# Weather Agent

This project uses an LLM-powered agent to answer weather questions with tools for:

- getting weather by city
- detecting the user's location when no city is provided

The main script is [weatherAgent.py](weatherAgent.py).

## Requirements

- Python 3.10+
- A virtual environment
- API keys for:
  - OpenWeatherMap
  - KodeKloud AI / OpenAI-compatible endpoint / Or any others

## Setup

1. Open a terminal in the project folder.
2. Create and activate a virtual environment:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

On macOS/Linux:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

3. Install dependencies:

```powershell
python -m pip install --upgrade pip
pip install -r requirements.txt
```

4. Create a `.env` file in the project root and add your keys:

```env
OPEN_WEATHER_API_KEY=your_openweather_api_key
KODEKEY_API_KEY=your_kodekey_api_key
```

## Run the app

```powershell
python weatherAgent.py
```

You will be prompted:

```text
Ask your question:
```

Example questions:

```text
What is the weather in London?
How hot is it in New York right now?
What is the weather here?
```

## How it works

- If the user provides a city, the agent calls the weather API for that city.
- If no city is given, it uses the user's public IP location and then fetches weather for that place.
- It returns the result in a natural-language response generated by the configured model.

## Notes

- The OpenWeather API is used for current weather data.
- The agent uses the model configured in [weatherAgent.py](weatherAgent.py) via `ChatOpenAI`.
- Make sure your `.env` file is not committed to source control if you are working in a shared repository.
